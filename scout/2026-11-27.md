## Attack
**Easlick, Conjecture 1**, in [`cases/easlick-dice-conj1`](../cases/easlick-dice-conj1/CASE.md).
- **Reproduction.** Every graph statistic in the paper agrees with ours: V, E, SCC counts and largest SCC for n = 3..10, and the n = 6 SCCs with their cycles.
- **Ambiguity.** The paper never defines "maximum length n". Its own evidence fits reading (A), "the longest cycle has length exactly n".
- **Reading (A): proved for 7 ≤ n ≤ 60 and n ∈ {70, 80, 90, 100}.** For each such n there is an explicit cycle of length n+1. `verify_cycles.py` re-checks each one exactly with `Fraction`.
- **Reading (B), "a cycle of length n exists": false at n = 7**, through an explicit 7-cycle. This is almost certainly not what the author meant, so it is **not a refutation**. It is a note that the statement needs a definition.

No counterexample today.
